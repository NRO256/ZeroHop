1. 概要
----------------------------------------------------------------------
ZeroHop は、サーバーを設置せず同一 LAN 内で安全に連絡を取り合う
ための、ポータブル単一実行ファイル (ZeroHop.exe) です。

会話履歴・パスワード・暗号鍵・表示名・接続先ピア情報をディスクへ一切
保存しない「ゼロパーシステンス」設計と、キーボード単体およびスクリーン
リーダー (NVDA / Windows ナレーター) での操作性を両立しています。


2. 主な機能
----------------------------------------------------------------------
- ゼロパーシステンス設計:
  会話履歴、パスワード、導出鍵、表示名、ピア一覧はメモリ上にのみ保持し、
  ログアウト・終了・異常終了時にゼロクリアします。起動時には一時作業
  フォルダ (cache/) の残骸を自動消去します。

- エンドツーエンド暗号化通信:
  ログイン時に Argon2id で鍵を導出し、用途別の 4 系統鍵へ分離します。
  UDP Beacon/Bye および TCP 全フレームを ChaCha20-Poly1305 AEAD で
  暗号化・認証し、二階層リプレイキャッシュ (全体 10,000 件 / 送信者別
  500 件 / 時刻窓 ±5 分) で再送攻撃を遮断します。鍵領域には VirtualLock
  を適用します。

- 4 重メモリガード:
  1 メッセージ本文最大 4 KiB (UTF-8)、スレッドあたり最大 1,000 件、
  保持ピア最大 64 件、会話メモリ総量既定 16 MiB (4〜32 MiB で設定可)
  の上限により、長時間稼働でもメモリ肥大化を防ぎます。

- 自動検出と手動ピア追加:
  暗号化 UDP ブロードキャスト (既定 UDP 45100) による自動検出に加え、
  UDP 遮断環境向けに IP とポートを指定して直接 TCP 接続 (既定 TCP
  45101) する手動ピア追加 (Ctrl+M) に対応しています。ポート競合時は
  自動フォールバックします。

- 到達確認と未達再送:
  1 対 1 チャットでは厳密 Ack、全体チャットでは集合 Ack (一部到達表示
  および未達相手のみへの再送) を備えています。

- 暗号化ファイル転送:
  最大 50 MiB までのファイル送受信に対応しています (Ctrl+Shift+F)。
  受信側の承諾ダイアログ後に 64 KiB チャンクで転送し、SHA-256 検証と
  揮発鍵による一時領域暗号化・ゼロ上書きシュレッディング削除を行います。

- UX・アクセシビリティ:
  仮想 ListView + 選択行 Enter による長文詳細モーダル (全文コピー可)、
  控えめな 5 種インメモリ効果音 (全消音・個別 ON/OFF 可)、トレイ通知
  (本文非表示設定可)、セッション内検索 (Ctrl+F)、Enter / Ctrl+Enter
  送信切替 (IME 変換確定時の誤送信防止)、自動離席 (既定 5 分)、ワンキー
  画面ロック (Ctrl+L)、ハイコントラスト自動追従・高 DPI に対応しています。


3. クイックスタート
----------------------------------------------------------------------
(1) 配布 ZIP を任意のフォルダに展開します (インストール不要)。
(2) ZeroHop.exe を起動します。
(3) 「表示名 (1〜32 文字)」と「パスワード (8 文字以上必須・12 文字以上の
    英数記号混在を推奨)」を入力してログインします。
(4) 同じパスワードを入力した同一 LAN 内のメンバーが自動的に接続先
    リストへ表示されます。
    ※ 接続先が見つからない場合は、「ツール」→「ルーム確認コード・
       通信情報」でルーム確認コードや待機ポートを確認し、必要に応じ
       て Ctrl+M (手動ピア追加) で相手の IP:Port を指定してください。


4. キーボードショートカット
----------------------------------------------------------------------
[グローバル・メニュー操作]
- Alt + A / E / T / H  : メニューバー各項目を開く
- F6 / Shift + F6      : 接続先リスト / 会話一覧 / 入力欄を巡回移動
- Ctrl + F             : セッション内メッセージ検索
- Ctrl + L             : ワンキー画面ロック (会話・ピア一覧を即時遮蔽)
- Ctrl + M             : 手動ピア追加 (IP・ポート指定接続)
- Ctrl + Shift + F     : ファイルを送信 (最大 50 MiB)
- F5                   : ネットワーク再検出 (NIC・ソケット再確認)
- Ctrl + Shift + L     : ログアウト確認ダイアログ (メモリ全消去)
- Ctrl + Shift + Del   : 現在表示中の会話表示をクリア
- Alt + F4             : 終了 (ログイン中は確認後に全消去して終了)

[ログイン・ロック画面]
- Enter                : ログインまたは画面ロック解除を実行
- Tab / Shift + Tab    : 入力欄・表示切替・ボタンを移動

[会話一覧・入力欄]
- 上下矢印キー         : 会話メッセージ行または接続先を選択
- Enter (会話一覧上)   : 選択メッセージの全文詳細ダイアログを開く
                         (コピー・再送可)
- Esc (詳細ダイアログ) : ダイアログを閉じて直前選択行へフォーカス復帰
- Ctrl + Enter (入力欄): 既定設定時のメッセージ送信 (Enter のみは改行)
- Enter (入力欄)       : 「Enterキーで送信」有効時の送信
                         (Shift+Enter で改行、IME 変換中は非送信)
- Ctrl + A (入力欄)    : 入力テキストを全選択


5. 設定ファイル (config.json) と起動オプション
----------------------------------------------------------------------
実行ファイルと同じフォルダに config.json が作成され、非機密の動作設定
のみを保存します (読み取り専用メディア上では保存をスキップします)。

- udp_port (既定 45100) / tcp_port (既定 45101): 待ち受けポート
- preferred_nic_ip: 優先使用するネットワークインターフェース IP
- max_memory_mb (既定 16, 範囲 4〜32): 会話ログ総メモリ上限
- sound_enabled / sound_on_login_logout / sound_on_peer_presence /
  sound_on_message: 効果音設定
- send_on_enter (既定 false): Enter キーでの送信切替
- hide_notification_preview (既定 false): トレイ通知の本文非表示
- auto_away_minutes (既定 5, 範囲 0〜60): 自動離席までの無操作分数

[コマンドラインオプション]
- --multi : 同一 PC 上での複数インスタンス起動を許可します
            (動作確認用。通常は単一インスタンスのみ許可)。


6. セキュリティ注意事項・脅威モデル上の制約 (重要)
----------------------------------------------------------------------
本ソフトをご利用になる前に、以下の仕様上の制約を必ずご確認ください。

(1) 前方秘匿性 (Forward Secrecy) はありません:
    本ソフトはサーバーレス即時通信のため、ルーム共通パスワードによる
    静的共有鍵 (PSK) 方式を採用しています。パスワードが漏洩または推測
    された場合、事前にネットワーク上でキャプチャされた過去の暗号化通信
    も復号され得ます。

(2) 同一ルーム内の表示名詐称:
    同一ルームの全参加者が同じ共通鍵を共有するため、ルーム内部者による
    表示名のなりすましを暗号学的には識別できません。

(3) パスワード運用:
    8 文字未満ではログインできません。信頼できるメンバー間でのみ、
    推測困難な 12 文字以上 (英数記号混在) のパスワードを使用し、
    定期的に変更することを強く推奨します。

(4) OS レベルのメモリ残存限界:
    休止状態ファイル (hiberfil.sys)、メモリ逼迫時の非ロック領域の
    ページング (pagefile.sys)、OS 管理者権限によるメモリダンプ、および
    ユーザーが手動コピーした Windows クリップボード履歴は、アプリ単体
    では完全遮断できません。

(5) 履歴非保存に伴う消失リスク:
    会話履歴はディスクへ一切保存されません。不意の PC 再起動や電源断、
    ログアウトにより会話内容は完全に失われます。業務上保存が必要な情報
    は各自で転記してください。


7. Windows Defender ファイアウォール許可手順
----------------------------------------------------------------------
- 初回起動・通信時に「Windows セキュリティの重要な警告」が表示された
  場合は、利用する信頼済みネットワーク (通常は「プライベート ネット
  ワーク」) へのアクセスを許可してください。

- 手動で許可する場合は、以下の手順で登録します。
  1. 「Windows セキュリティ」→「ファイアウォールとネットワーク保護」
     →「ファイアウォールによるアプリケーションの許可」を開く。
  2. 「設定の変更」→「別のアプリの許可」から ZeroHop.exe を追加し、
     プライベートネットワークにチェックを入れる
     (または UDP 45100 / TCP 45101 の受信を許可する)。

- 共有 PC の制約:
  管理者権限のない共有 PC 環境ではファイアウォール受信許可を追加できず、
  他端末からの着信がブロックされる場合があります。その場合は事前許可済み
  端末への発信や、手動ピア追加 (Ctrl+M) と併用してください。
